SWARMKIND / PHP PRECAUTION

STRICT BLOCKING

You choose which hosts load.

Unapproved HTTP(S) and WebSocket requests are blocked. Expect broken pages until you approve their required hosts. Use a separate browser profile, and close existing website tabs before browsing with the extension.

Approval permits PHP too. Neither approval nor absence from a PHP list means a site is safe. This extension does not patch servers.

Approved hosts

Exact hostnames only; subdomains require separate approval. An approval applies to all ports and both HTTP and HTTPS (and WebSockets).

    PHP evidence list

    Lists explain blocks; strict mode already blocks every unapproved host. Entries are historical technology reports, not a list of vulnerable sites.

    Importing replaces the previous local import. It never changes approvals. Files stay in this browser profile.

    Installation and recovery

    Pin the extension to reopen this page. If browsing is too disrupted, turn PHP Precaution off on your browser’s Extensions page. Reload pages after changing approvals. Close already-open website tabs: loaded content and existing connections are not undone.

    Unpacked installs do not update automatically. Download a new release, extract it, and use Reload on the Extensions page. Keep the extension folder in place.

    No accounts, analytics, remote lookups or background list downloads. Browser-internal pages, other profiles, other apps and incognito windows where this extension is not enabled are outside its scope. Service-worker cached responses and already established connections may bypass network rules.
